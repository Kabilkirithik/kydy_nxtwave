## Complete Frontend Description: **Kydy - AI Learning Platform**

### 🎯 **Overview**
Kydy is a personal AI-powered learning companion built with **React**, **TypeScript**, **Tailwind CSS**, and **shadcn/ui**. It provides interactive live teaching sessions where users can learn any subject with an AI tutor.

### 📄 **Pages**

#### 1. **Landing Page (`/`)**
The main marketing page with:
- **Navbar**: Fixed navigation with logo, Home/Features links, and "Get Started" CTA. Becomes translucent on scroll
- **Hero Section**: Gradient background with animated floating elements, main headline "Learn Anything with Your Personal Kydy Tutor", and two CTAs (Start Learning, See How It Works)
- **Features Section**: 6 feature cards in a grid (Live AI Sessions, Interactive Chat, Smart Notes, Hand Raise, Adaptive Learning, Session Library)
- **Footer**: Brand logo, description, and quick links

#### 2. **Features Page (`/features`)**
Detailed breakdown of all 6 features with:
- Alternating left-right layout for each feature
- Icon, title, description, and benefits list
- Gradient backgrounds and CTA sections

#### 3. **Chat Page (`/chat`)**
The main chat interface to start learning:
- **Left Sidebar**: Logo, "New Chat" button, navigation to Previous Sessions/Settings, and "Back to Home"
- **Main Area**:
  - Welcome message with 6 suggested topic cards (Mathematics, Science, Programming, History, Geography, Language)
  - Pro tip about starting sessions
  - Chat messages with user/AI avatars
  - Typing indicator animation
  - "Start Live Session" button appears after conversation
- **Input Area**: Text input with send button

#### 4. **Session Page (`/session`)**
The live learning session interface:
- **Header**: Back button, topic title, live status indicator with timer, "End Session" button
- **Video/Content Area**: 
  - Simulated AI teaching display with pulsing avatar
  - Video controls (play/pause, volume, fullscreen)
- **Chat Panel**: 
  - **Hand Raise Feature**: Button to pause session and ask questions
  - Chat messages between user and AI
  - Input disabled until hand is raised
- **Notes Panel**: 
  - Note-taking textarea
  - List of saved notes with timestamps
  - Delete functionality

#### 5. **Library Page (`/library`)**
Browse past learning sessions:
- **Left Sidebar**: 
  - Logo and navigation
  - Subject list with session counts (Mathematics, Science, Programming, History, Language)
- **Main Area**:
  - Subject grid view with icons and session previews
  - Individual session cards with thumbnails, duration, and date
  - "Start New Session" card
  - Search functionality

#### 6. **Settings Page (`/settings`)**
Comprehensive settings interface (601 lines):

4. **No Data Persistence**: Notes, sessions, and settings are not saved between page refreshes
